# Glide — conversion landing, variant C "Signal"

Same anatomy and reviewed copy as `apps/glide-landing`, reskinned: monochrome slate + lime
highlighter accent on white, Space Grotesk + Inter, sharp corners and 1px borders. Generated from
the base via `build-variant.mjs` (style/fonts/favicon/brand-hex swap only — copy is byte-identical).
Serve: `python -m http.server 8915 -d apps/glide-landing-c` or `serve.mjs --dir apps/glide-landing-c --port 8925`.
