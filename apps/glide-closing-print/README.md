# Glide — "Closing Print" homepage candidate

Static single-page site, no build step. Serve locally with `python -m http.server 8912 -d apps/glide-closing-print`
(or `node <eng-site>/scripts/serve.mjs --dir apps/glide-closing-print --port 8922`); deploy by copying this folder
to any static host. CTA links (`/register`, `/login`, `/contact`) assume same-domain deployment with the Glide app.
Art direction (unanimous winner of a 5-direction / 3-judge panel): see `DIRECTION.md`.
Siblings: `apps/glide` (emerald corridor), `apps/glide-blockgauge` (dark instrument tower).
